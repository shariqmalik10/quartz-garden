Production work rewards abstraction. Learning sometimes asks for the opposite.

When I built a [[projects/neural-network|neural network from scratch]], the point was not to replace mature frameworks. It was to make the hidden machinery tangible: forward passes, gradients, parameter updates, and the small mistakes that reveal whether I actually understand them.

I like keeping these compact implementations next to larger projects because they answer a different question. A production repository shows that I can assemble a dependable system. A from-scratch experiment shows where my mental model has edges.

Both are forms of craft. One hides complexity on purpose; the other opens it up long enough to learn from it.
