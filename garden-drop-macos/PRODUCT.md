# Product

## Platform

macOS 14+ on Apple Silicon.

## Purpose

Garden Drop is a nearly invisible capture utility for Shariq's private Obsidian vault. It turns a copied link, image, or text fragment into a durable Markdown capture without asking the user to leave their current application or wait for GitHub.

## First milestone

Prove the local capture contract in a normal window before adding notch measurement, hover activation, clipboard inspection, metadata enrichment, or nightly publication.

## Truth and constraints

- The vault is the source of truth; captures are local and immediate.
- A capture never pushes to GitHub during save.
- Garden/private visibility is explicit in the note frontmatter and UI copy.
- The first UI follows native macOS typography, controls, keyboard navigation, appearance, and accessibility expectations.
- The application must preserve all entered text when a write fails.
